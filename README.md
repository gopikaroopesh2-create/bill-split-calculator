Bill Split Calculator

A simple bill splitting application developed using Python and Tkinter.

Features

- Enter total bill amount
- Enter number of people
- Calculate tip percentage
- Display final bill and per-person amount
- Reset inputs
- Input validation and error messages

Technologies Used

- Python
- Tkinter

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run "python bill_split.py".

Purpose

This project was created to practise Python programming, GUI development, functions, and input validation.
